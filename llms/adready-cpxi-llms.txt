# AdReady (CPXi) / Digital Remedy

> Digital Remedy operates an omnichannel advertising management platform — marketed as the Digital
> Remedy Platform and historically as AdReady+ — for independent agencies, brands and media companies.
> It covers media planning, RFPs, insertion-order and line-item management, programmatic / CTV / DOOH /
> social execution, pixel-based attribution (Flip), incrementality and brand-lift measurement, and
> white-label reporting. AdReady began as a Seattle self-serve ad-building tool, was acquired by CPXi
> in 2013, and is today part of Digital Remedy, which has since combined with Compulse.

This file is generated by API Evangelist. Digital Remedy publishes no llms.txt of its own
(https://www.digitalremedy.com/llms.txt returns 404) and no developer portal.

## What an agent should know first

- **There is a real, current OpenAPI 3.1 description and it is public.** It is served anonymously at
  https://platform.digitalremedy.com/v3/api-docs with a Swagger UI at
  https://platform.digitalremedy.com/swagger-ui.html — 285 paths, 355 operations, 285 schemas.
- **The API itself is not open.** It is the first-party backend of Digital Remedy's own web
  application. There is no developer program, no public sign-up, no pricing, and no documentation
  beyond the generated Swagger UI. Every business operation returns HTTP 401 without a session.
- **Credentials are provisioned by Digital Remedy**, obtained through
  https://www.digitalremedy.com/contact-us/ — not by self-service registration.
- **Do not treat this API as automatable without a contract with the vendor.** It has no idempotency
  keys, no rate-limit signalling, no problem-details errors and no deprecation policy.
